Vi suggerisco alcuni plugin per Visual Studio Code (immagino che ci sia qualcosa di simile anche per Visual Studio), che supportano uno sviluppo comodo.

Che intendo per sviluppo comodo? Intendo che questi plugin aiutano a tenere il codice organizzato, ad appuntare implementazioni da completare o effettuare al meglio i miei test.

![](http://www.eleonorarocchi.it/wp-content/uploads/2019/07/image-3.png)

### 1) Angular Snippets

Il primo è [Angular Snippets](https://marketplace.visualstudio.com/items?itemName=Mikael.Angular-BeastCode) di John Papa. Angular Snippets suggerisce snippet, appunto, di codice, con la semplice digitazioni di key word che hanno affinità con il codice suggerito.

### 2) Debugger for Chrome

Il secondo è [Debugger for Chrome](https://marketplace.visualstudio.com/items?itemName=msjsdiag.debugger-for-chrome). Debugger for Chrome consente di collegare un'istanza apposita di chrome a Visual Studio Code per poter debuggare Typescrip (nel mio caso) con molta facilità.

### 3) TODO Highlight

Il terzo è [TODO Highlight](https://marketplace.visualstudio.com/items?itemName=wayou.vscode-todo-highlight). Todo Highlight è in grado di evidenziare con diversi colori label come TODO e FIXME, in modo da balzare subito all'occhio scorrendo un file.

### 4) Todo Tree

Il quarto è [Todo Tree](https://marketplace.visualstudio.com/items?itemName=Gruntfuggly.todo-tree). Todo Tree propone in una paletta organizzata ad albero le varie label tipo TODO e FIXME, al fine di poterle consultare agevolmente e soprattutto non dimenticare in qualche file sperso.

Questi sono i plugin che supportano uno sviluppo comodo per Visual Studio Code che consiglio.
